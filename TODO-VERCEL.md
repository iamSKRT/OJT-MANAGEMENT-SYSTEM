# Deploy to Vercel

## Steps:
- [ ] Step 1: Commit git changes
- [ ] Step 2: Install Vercel CLI (`npm i -g vercel`)
- [ ] Step 3: `vercel login`
- [ ] Step 4: `vercel` (deploy)
- [ ] Step 5: Set Vercel env vars (VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY)
- [ ] Step 6: Redeploy if needed (`vercel --prod`)
- [ ] Complete
